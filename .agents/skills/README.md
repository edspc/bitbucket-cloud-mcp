# Project skills

Each skill directory contains a portable `SKILL.md` with a name, description and
task workflow. Use the matching workflow together with the repository rules;
skills do not replace those rules or expand the user's requested scope.

| Skill | Use for |
| --- | --- |
| [add-mcp-tool](add-mcp-tool/SKILL.md) | Adding or extending a Bitbucket MCP tool |
| [diagnose-bitbucket-api](diagnose-bitbucket-api/SKILL.md) | Diagnosing API, authorization, rate-limit or pagination failures |
| [release-mcp](release-mcp/SKILL.md) | Preparing and publishing a requested server version |

The canonical files are in `.agents/skills`; `.claude/skills` is a symlink.
